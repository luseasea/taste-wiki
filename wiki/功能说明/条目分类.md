# 条目分类

> FEAT-007｜整理：2026-11-10｜需求：资料整理待审核｜实现 / 上线：未核实｜审核人 / 时间：尚无。
> 依据：Epic 7·US-24·2、US-25·4、US-26·2、US-27·5；分类技术对接 v1.0（2026-07-19）。

## 四类含义

| 分类 | 资料中的含义 | 例子 |
| --- | --- | --- |
| 玩乐 | 娱乐、出行、运动等体验和场所 | 展览、健身房、电影院 |
| 美食 | 吃喝及相关场所 | 餐厅、咖啡馆、食材 |
| 好物 | 实体商品 | 书籍、服饰、电子产品 |
| 其他 | 不属于上述三类的对象 | App、数字内容、服务 |

文件夹顺序为玩乐、美食、好物、其他。分类依据对象的具体含义，不只看名称；技术文档以“电影归其他、电影院归玩乐”等说明边界。

## 哪些新建需要自动分类

| 新建渠道 | 分类方式 |
| --- | --- |
| 底部添加入口 | 没有文件夹或榜单上下文，自动判断 |
| 文件夹内 | 沿用当前分类，不调用自动分类 |
| 榜单编辑页 | 沿用当前榜单类别，不调用自动分类 |

理由是已有上下文时无需再猜分类。页面及返回规则见 [新建与浏览](条目新建与浏览.md)。

## 手动移动与批量移动

单条详情 → 移动 → 选择其他三个分类之一 → 关闭弹窗、提示成功并更新详情标签。文件夹多选也可批量移动；成功后保持当前文件夹的多选态，已移走条目从当前列表消失。

手动移动被视为分类纠错信号，不意味着一次移动立即训练模型。技术文档建议累计纠错后离线更新，尚无实际实现验证；具体策略需要时再查来源。

## 已知缺口

技术文档写调用失败或超时归“其他”并记录告警，但部分置信度条件的不等号或数值被截断，部分流程与接口为空。完整阈值逻辑不可从残缺表格反推，见 [Q-004](../../questions/待确认事项.md#q-004-导出资料存在空章节空链接和缺图)。

移动是否影响既有榜单类别限制、重复移动和失败如何反馈，尚未形成完整结论。
