# 条目复制

> FEAT-005｜整理：2026-11-10｜需求：资料整理待审核｜实现 / 上线：未核实｜审核人 / 时间：尚无。
> 依据：Epic 7 PRD·US-24·3、US-26、US-28、US-29；6.24 决策清单·来源 ID 与复制后引导。

## 目标与流程

复用他人推荐的对象，再表达自己的排序，降低重新创建的成本。

查看他人榜单 → “我也来新建一个” → “复制它的条目，自己排序” → 原页面蒙版多选 → 复制入个人库 → 完成态点击“前往条目库创建新榜单” → 进入分类文件夹多选态，预选刚复制的条目 → 可调整选择并创建榜单。

也可选择“完全自己新建榜单”，进入空白创建流程。复制为个人写入操作，未登录先登录并回到复制多选态；浏览他人榜单无需登录。

## 选择与后续使用

- 未选中时复制按钮置灰；不做查重，允许重复复制。
- 全选是否出现及上限拦截，见 [容量](条目库容量.md#不同操作达到容量时怎么办)。
- 进入文件夹后可补选、取消选择，也可批量移动或删除；未选中时批量操作置灰，X 退出多选。分别见 [分类](条目分类.md)、[删除](条目删除.md)。
- 复制后创建预填源榜单标题和类别，允许修改；待评级区使用最终勾选项。普通文件夹多选创建则预选当前分类、标题自行填。完整创建榜单主题尚待整理。

## 复制后的关系

资料要求新条目与源条目 ID 建立关联以便追溯。**跨用户是否持续同步仍未明确，不能仅凭来源 ID 推导。** 源作者修改或删除、接收方编辑各自的影响见 [Q-007](../../questions/待确认事项.md#q-007-跨用户复制后的同步边界未确认)。

个人库内同一条目在多个榜单复用的同步见 [编辑与同步](条目编辑与同步.md)。

## 中断及历史变化

复制期间可退出，原文要求“已完成保留，未完成丢弃”。完成点、部分失败及重试机制未定义，见 [Q-008](../../questions/待确认事项.md#q-008-复制流程的数据完成点与失败处理缺少定义)。动画进度不是保存证据。

6.24 曾讨论复制后用弹窗引导创建，后续 PRD 改用文件夹多选和独立创建页。US-29 局部说明写创建阶段推荐入口已移除，对比表却残留“有”，见 [Q-005](../../questions/待确认事项.md#q-005-产品概览与管理表未同步后续需求)；不据旧表承诺入口存在。

7.19 晚会又讨论简化复制加载及取消进度条，与 PRD 动画参数未完全同步，见 [Q-014](../../questions/待确认事项.md#q-014-719-会议摘要与需求中的时间和交互未对齐)。此前流程是该版需求的记载，最终动效和跳转需进一步核对，不能仅凭文件标题日期判定。
