## 产品概述

### 产品定义

**个人榜单 · Taste** 是一款微信小程序，让用户把生活经验做成带评级的榜单，分享给真正会听你推荐的人。

### 品牌主张

> **Not popular. Personal.**

不是大众流行，而是你个人的品味表达。

### 产品定位

| 维度 | 说明 |
| --- | --- |
| 核心差异 | 以"人"为核心的轻量榜单工具，**拖拽式五档评级**是最大交互差异化 |
| 不是什么 | 不是大众点评（店为中心）、不是小红书（社区内容中心）、不是豆瓣（作品评分中心） |
| 五档评级 | 🏆夯 → 👑顶级 → 😎人上人 → 🤖NPC → 💀拉完了（高→低，已有国民级认知度） |
| 信任模型 | 熟人推荐，而非算法推荐。分享即分发 |

### 目标用户

任何有"推荐欲"的人——想把自己去过的好店、用过的好物、看过的好作品整理成榜单发给朋友的人。

冷启动以**校园场景**为第一战场（在校同学是核心力量），逐步扩展到职场人、兴趣爱好者。

### V1.0 范围

**做**：创建榜单、添加条目、拖拽评级、分享传播

**不做**：付费、社区、首页精选推荐、AI生图、关注/订阅、个人主页

### 成功指标（上线3个月）

- 50个有效榜单（每个榜单浏览量超过50人，自己人占10\~20%）

- 30%创建者分享过至少一次

- 日活持续增长

### 技术栈

微信小程序 · Taro + React + TypeScript + SCSS · 微信云开发（CloudBase）

## Epic 1：用户进入与登录

> **目标**：让用户以最低摩擦进入产品，看到产品价值后再登录。

---

### US-01 主动搜索进入——品牌引导

**As a** 通过微信搜索找到Taste的新用户
 **I want** 在登录前就能了解这个产品是做什么的
 **So that** 我不必一上来就被要求授权登录

**Acceptance Criteria**：

- [ ] 首次打开小程序，展示品牌欢迎页（Taste Logo + "Not popular. Personal."），1.5秒后自动进入引导页

- [ ] **仅首次打开展示**：后续打开直接进入"我的榜单列表页"，不再经过引导

- [ ] 引导共2屏：

 - ① Taste是什么——把你的生活经验做成榜单，发给真正会听你推荐的人

 - ② 核心玩法——拖拽式五档评级 + 创建后一键分享你的品味

- [ ] 每屏**右上角**有"跳过"按钮，底部有圆点进度指示器

- [ ] 引导结束后进入"我的榜单列表页"（空状态）

**优先级**：P0

---

### US-02 微信登录

**As a** 想创建榜单的用户
 **I want** 完成登录并设置个人信息
 **So that** 朋友在榜单上能认出我

**Acceptance Criteria**：
- [ ] 引导页结束后点击"创建第一个榜单"按钮 → 跳转到**个人信息设置页**

- [ ] 个人信息设置页包含：

 - **提示文案**："让朋友认出你"（副文案："在分享榜单的时候，朋友会看到你的名字"）

 - **选择头像**：默认显示吉祥物头像，点击后弹出微信原生头像设置弹窗

 - **昵称输入框**：默认提示词"让朋友认出你"，限制10字以内；同时提供"使用微信昵称"快捷选项

 - **隐私条款与用户协议**：勾选框（两个文档内容之后再做）

- [ ] 底部按钮"登录并进入"：三个条件全部满足（已设置头像 + 已填写昵称 + 已同意条款）才可点击，否则置灰

- [ ] 如果用户返回/退出个人信息页（拒绝登录），只能重新点击"创建第一个榜单"再次进入

- [ ] **异常**：登录失败时Toast提示"登录失败，请重试"

**优先级**：P0

---

### US-03 通过分享进入——免登录查看

**As a** 通过朋友分享链接/卡片进入的用户
 **I want** 不登录就能直接看到榜单完整内容
 **So that** 我不会被登录流程挡住，先看到价值再决定要不要用

**Acceptance Criteria**：

- [ ] 点击微信分享卡片或扫描小程序码 → 直接进入榜单详情页（查看态）

- [ ] 无需登录即可查看榜单全部内容：评级分区、条目卡片、条目详情弹窗

- [ ] 榜单详情页底部固定显示"我也来创建一个"按钮

- [ ] 点击"我也来创建一个"→ 在本页直接弹出微信授权弹窗 → 登录成功后直接进入榜单创建页（同US-02登录逻辑）

- [ ] **异常**：加载榜单失败时Toast提示"加载失败，请重试"

**优先级**：P0

## Epic 2：榜单管理

> **目标**：用户可以创建、查看、编辑、删除自己的榜单。

---
### US-04 创建榜单

**As a** 已登录用户
 **I want** 创建一个新榜单
 **So that** 我可以开始整理我的推荐清单

**Acceptance Criteria**：

- [ ] 入口：首页底部"创建第一个榜单"按钮 + 首页空状态引导按钮

- [ ] 点击后弹出**半屏弹窗**，填写：

 - 榜单名称（必填，最长20个中文字符）

 - 主题标签（必填，四选一：美食 / 玩乐 / 好物 / 其他）

- [ ] 名称输入框下方随机显示一条灵感提示文案（不上滚，每次进入随机一条）；文案池包含：

 - 北京华贸午餐地图 / 周末遛娃好去处 / 大学城周边美食图鉴 / 期末复习宝藏自习室 / 宿舍好物推荐清单 / 职场新人必读书单 / 下班小酌据点合集 / 通勤必备好物 / 出差必备行李清单 / 新手健身入门指南 / 宅家幸福感好物 / 周末一人食餐厅推荐

- [ ] 点击"创建榜单"，榜单立即创建并自动保存，关闭弹窗，跳转到榜单编辑页

- [ ] 创建时无需上传封面图（V1.0榜单无封面图）

- [ ] **异常**：保存失败时Toast提示"保存失败，请重试"

**优先级**：P0

---

### US-05 查看我的榜单列表

**As a** 已登录用户
 **I want** 在首页看到我创建的所有榜单
 **So that** 我可以管理我的榜单

**Acceptance Criteria**：

- [ ] 首页顶部显示用户头像（纯展示，V1.0不显示昵称、不跳转）

- [ ] 下方列表展示所有已创建的榜单，每条显示：榜单名称、主题标签

- [ ] 创建时间和最近更新时间 V1.0不做（下一版再加）

- [ ] 按**最近更新时间从近到远**从上到下排序

- [ ] 点击榜单进入榜单编辑页

- [ ] 每位用户最多创建5个榜单
- [ ] **空状态**：无榜单时展示品牌插画 + "你还没有榜单" + 引导文案 + "创建第一个榜单"按钮

- [ ] **异常**：加载榜单列表失败时Toast提示，显示重试按钮

**优先级**：P0

---

### US-06 编辑榜单信息

**As a** 已登录的榜单创建者
 **I want** 修改榜单名称和标签
 **So that** 我的榜单信息可以随需求更新

**Acceptance Criteria**：

- [ ] 在榜单编辑页顶部，点击榜单名称 → **内联编辑**（原地编辑，不弹窗）

- [ ] 点击标签 → 内联切换标签选择

- [ ] 修改后**自动保存**

- [ ] **空值校验**：如果删除标题到0字并点击其他地方失焦，该字段标红提醒，helper处显示"标题不能为空"，其他地方保持原标题不变

- [ ] 查看者当前正在看榜单时，创建者的修改不会实时推送刷新；但查看者下次进入时看到最新版本

**优先级**：P1

### US-07 删除榜单

**As a** 已登录的榜单创建者
 **I want** 删除我不再需要的榜单
 **So that** 我可以释放榜单名额

**Acceptance Criteria**：

- [ ] 榜单编辑页有删除按钮

- [ ] 点击删除 → 弹出确认弹窗："确定删除该榜单？删除后无法恢复"

## Epic 3：条目添加与评级拖拽（核心体验）

> **目标**：这是Taste最核心的差异化交互。用户能轻松添加条目，并通过拖拽完成五档评级。

---

### US-09 添加条目

**As a** 榜单创建者
 **I want** 在榜单中添加条目
 **So that** 我可以构建榜单内容

**Acceptance Criteria**：

- [ ] 榜单编辑页底部暂存区有"+ 添加"按钮

- [ ] 点击 → 从底部弹出半屏弹窗

- [ ] 弹窗包含三个字段：

 - 条目名称（必填，最长10个中文字符，输入框自动聚焦）

 - 条目图片（选填，支持拍照或从相册选择，≤4MB；图片自动填充满上传区域；上传后区域显示切换icon，可点击更换图片）

 - 条目简介（选填，一句话描述）

- [ ] 点击确认 → 弹窗关闭，暂存区新增一张正方形卡片
- [ ] **卡片展示规则**：

 - 有图片：图片为底，自动填充正方形区域

 - **无图片**：不同梯度的灰色背景 + 居中显示一个大的条目名称首字 + 下方居中显示小字条目全名（超过5个字则省略为前4字+…）

- [ ] 新增卡片排列在暂存区最左侧（最新添加在左，可左右滑动查看更多）

- [ ] **异常**：上传图片失败时，在图片上传区域显示"图片上传失败，请重试"

**优先级**：P0

---

### US-10 榜单编辑页——页面布局

**As a** 榜单创建者
 **I want** 在榜单编辑页看到清晰的五档评级区和我创建的条目
 **So that** 我知道如何组织和评级我的条目

**Acceptance Criteria**：

- [ ] 页面顶部显示榜单名称和标签（可点击内联修改）

- [ ] 右上角显示分享按钮

- [ ] 上部（约3/4屏幕）为五档评级表格区，表格两列布局：

 - 左列：评级标签（从上到下：🏆夯 / 👑顶级 / 😎人上人 / 🤖NPC / 💀拉完了）

 - 右列：条目卡片放置区

- [ ] 下部（约1/4屏幕）为条目暂存区：水平滚动，展示未评级条目卡片

- [ ] **暂存区头部**：显示"待评级 · N"（N为未评级条目数量），小字提示"拖至上方区域完成评级"

- [ ] **评级行高度与布局规则**：

 - 每个评级行的默认高度 = 暂存区卡片的高度

 - 条目卡片横向排列，排满一行后自动换行扩展

 - 榜单表格区是**可上下滚动的区域**，拖拽到边界时自动上下滚动

 - 5个评级等级始终可见

 - 当条目过多导致评级区总高度超出屏幕时，所有卡片自动缩小为原来的一半

 - 每个评级等级最多容纳 **11个条目**

- [ ] **空状态**：榜单无任何条目时，暂存区为空，显示提示"拖至上方区域完成评级"

**优先级**：P0

---

### US-11 拖拽条目到评级区

**As a** 榜单创建者
 **I want** 通过拖拽将条目放入对应的评级等级，并在等级内自由排序
 **So that** 我可以直观地为每个条目评级和排位

**Acceptance Criteria**：
- [ ] **触发**：手指长按条目卡片约0.2秒，触发震动反馈（haptic），卡片浮起（阴影加深+轻微放大）

- [ ] **拖动中**：卡片跟随手指移动；手指经过评级行时该行高亮（背景色变化+边界发光），表示可以放入

- [ ] **松手**：卡片落入目标位置，播放落位动效（微小弹性动画）；**落位后暂存区数量才更新**（"待评级 · N"减少）

- [ ] **跨区拖动**：支持从任意评级区拖到任意其他评级区（夯↔拉完了等所有方向）

- [ ] **拖入暂存区**：支持将卡片从评级区拖回暂存区（双向、可逆）

- [ ] **从暂存区拖出**：支持从暂存区拖入任意评级区

- [ ] **区域内排序**：V1.0支持在同一个评级区内手动拖拽排序——卡片可以前后移动调整顺序，松手即保存位置

**优先级**：P0

---

### US-12 编辑条目

**As a** 榜单创建者
 **I want** 修改已添加条目的信息
 **So that** 我可以更新或完善条目内容

**Acceptance Criteria**：

- [ ] 点击条目卡片（无论在暂存区还是评级区）→ 弹出半屏编辑面板

- [ ] 面板内可修改：条目名称、图片、简介

- [ ] **编辑面板不可修改评级等级**——评级只能通过拖拽改变

- [ ] 修改后确认保存

- [ ] **排序无草稿**：所有拖拽排序操作即时自动保存，没有"草稿"或"确认"的概念，拖到位就生效

**优先级**：P1

---

### US-13 删除条目
**As a** 榜单创建者
 **I want** 删除榜单中的条目
 **So that** 我可以移除不需要的内容

**Acceptance Criteria**：

- [ ] 点击条目卡片 → 弹出半屏编辑面板

- [ ] 面板底部有"删除条目"按钮

- [ ] 点击即删除，无二次确认弹窗

- [ ] 删除后条目从暂存区/评级区消失

**优先级**：P1

## Epic 4：分享与传播

> **目标**：分享是V1.0唯一的增长手段。创建者能方便地分享榜单，接收者获得良好的查看体验。

---

### US-14 生成分享卡

**As a** 榜单创建者
 **I want** 生成一张精美的榜单分享卡片
 **So that** 我可以在微信里分享给我的朋友

**Acceptance Criteria**：

- [ ] 榜单编辑页**右上角**分享按钮

- [ ] 点击分享 → 进入分享卡生成页

- [ ] **分享卡生成页结构**：

 - **顶部导航栏**（蓝色背景）：左侧返回箭头（回到上一页）、中间标题"生成分享图"、右侧小程序菜单和关闭按钮

 - **核心分享卡片**（居中展示）：


 用户信息区：头像 + 用户名 + "给你的私人收藏" + 评级数据（如"20个评级、已被260人围观"） + 右上角分类标签

 - 品牌信息区：底部 #Taste 品牌标识 + slogan（Not popular. Personal.）+ 小程序二维码


 - **底部操作栏**：


 "微信分享给朋友"按钮：唤起微信分享，将此卡片发送给好友

 - "保存为图片"按钮：将分享卡片保存到手机相册


- [ ] V1.0不设分享卡生成失败的降级方案

**优先级**：P0

### US-15 微信转发——原生分享卡片

**As a** 榜单创建者

- [ ] 原生分享卡片信息：

- [ ] 点击分享卡片 → 直接进入该榜单详情页（查看态）

**As a** 通过分享链接进入的查看者

 **So that** 我能了解创建者的推荐

**Acceptance Criteria**：

- [ ] 页面顶部展示：榜单名称、主题标签、创建者头像+昵称（纯展示，不可点击）、创建时间、最后更新时间

- [ ] 下方展示五档评级表格（只读），五个评级分区从上到下排列，条目卡片不可拖拽

- [ ] 每个评级区内的条目以正方形卡片展示，紧凑排列

- [ ] 页面底部固定栏："我也来创建一个"按钮（主色醒目）

- [ ] 进入时展示榜单当前最新版本；如果查看者在浏览过程中创建者更新了榜单，当前页面不实时刷新，下次进入时看到最新版本

- [ ] **空状态**：榜单无条目时不显示文字提示

- [ ] **异常**：榜单已删除时展示"榜单消失了" + 插画；网络加载失败时Toast提示 + 显示重试按钮

**优先级**：P0
