## V1.0 关键产品决策

- 五档评级：🏆夯 → 👑顶级 → 😎人上人 → 🤖NPC → 💀拉完了

- 条目字段：名称（必填）+ 图片（选填）+ 简介（选填）

- 可见性：默认公开 + 仅链接可见

- 分享方式：分享卡 + 微信转发

- 不做：付费、社区、首页推荐、AI 生图、个人主页
