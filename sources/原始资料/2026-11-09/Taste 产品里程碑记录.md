### 2026-07-11 更新

- **Epic 6 Grooming 完成**：口令识别改为双流程（登录 Happy Pass 静默 + 手动输入兜底），口令码格式加密至 4 位字母（≈3,650 万组合），POI 选型确认使用 wx.choosePoi

- **AI 前瞻讨论完成**：AI 推荐用大模型可行（DeepSeek，≈240 元/年），AI 自动分类需 embedding + 向量化，一期只做四分类

- **开发排期确认**：本周（7/11-7/17）Epic 6 全部开发，下周开始 Epic 7

### Phase 2 核心目标

1. **增长破圈**：口令码打通小红书/抖音外部分发
1. **降低门槛**：条目库 + 批量复制，提升「查看者→创作者」二次转化率

1. **体验打磨**：Bug 修复 + 互动反馈 + 基础体验补全

### Phase 2 优先级总览

| **优先级** | **功能** | **说明** |
| --- | --- | --- |
| **P0** | 口令码 | 分享自动生成口令码，外部分发唯一通道（小红书/抖音/社群） |
| **P0** | 条目库 + 批量复制 | 个人条目库 + 从他人榜单多选复制条目，直接关联二次转化 |
| **P0** | Bug 修复 | 光标闪跳、页面微抖、首页缺分享入口 |
| P1 | 榜单点赞 | 显示点赞人头像+名称，探索贴纸墙等轻量互动形式 |
| P1 | 收藏/历史记录 | 留存优化，有余力则优先做 |
| P1 | POI 地点标记 | 条目绑定地理位置，为 Phase 3 智能推荐打基础 |
| P1 | 复制追踪 | 创作者查看传播链路（聚合数据），不暴露具体谁复制 |
| P1 | 图片放大查看 | 基础体验补全 |
| P1 | 吉祥物按等级切换 | 品牌趣味性 + 评级区辨识度 |
| P2 | 标题可复制等 4 项 | 运营期调研/有余力则做 |
