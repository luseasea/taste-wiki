# 提示词测试方法与数据集

> **目的**: 让产品经理无需写代码就能验证提示词效果
> **测试对象**: AI 自动分类 + AI 智能推荐 两套提示词

---

## 一、PM 怎么测提示词？三种方式

### 方式一：用 Claude 做「模拟裁判」（推荐，零门槛）

**原理**：Claude 本身就是一个大模型，可以直接运行你的提示词并给出结果。你把 System Prompt + User Prompt + 测试数据粘贴给 Claude，让它按提示词执行分类或推荐。

**优点**：你已经会用（就在当前对话里），改完提示词立刻能看效果
 **局限**：Claude 不是最终上线的 DeepSeek/Embedding 模型，结果会有差异，但**逻辑正确性可以验证**

**操作步骤**：

1. 把测试用例（见下文）粘贴给我

1. 我按照提示词逻辑给出分类/推荐结果

1. 你对比「期望结果」和「实际结果」

1. 发现偏差 → 分析是提示词问题还是测试用例表述问题 → 修改提示词 → 重新测试

### 方式二：用 DeepSeek 网页版（测试推荐提示词）

**原理**：AI 推荐用的就是 DeepSeek，直接在 DeepSeek 官网测试最接近真实效果。

**操作步骤**：

1. 打开 [https://chat.deepseek.com]()

1. 在「System Prompt」位置粘贴「AI 智能推荐 - 提示词」文档中的 System Prompt

1. 在对话框中粘贴一个 User Prompt（用下面的测试用例）

1. 看输出结果是否符合预期

**优点**：和线上效果最接近
 **局限**：DeepSeek 网页版可能不支持单独设置 System Prompt（需用 API Playground），可作为补充验证
### 方式三：用测试数据集批量验证（正式验收用）

**原理**：准备 ≥200 条标注好的测试数据，让技术侧跑批量测试脚本，产出准确率报告。这是 7.1 会议确定的正式验收流程。

**操作步骤**：

1. 你准备测试数据集（见下文）

1. 交给继超/天宇，由他们写脚本批量跑

1. 产出准确率报告 → 你 review → 针对性修改提示词
