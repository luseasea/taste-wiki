# Taste 项目知识库

了解项目、查进度与功能规则，和 AI 一起讨论需求、形成产品方案。

## 和 AI 一起用

复制这句话，发给支持网页读取的 AI：

```text
请读取这份指南，作为我的 Taste 项目助手，按其中约定回答问题或协作：https://raw.githubusercontent.com/luseasea/taste-wiki/main/开始使用.md
```

后面直接加上你的问题，例如：

- 产品现在进度如何？
- 删除条目和删除榜单有什么区别？
- 我是新来的产品同事，带我了解 Taste。
- 业务提出一个痛点，和我讨论方案并整理成产品需求文档 [PRD]。

无需先读完整仓库。AI 会按问题查找相关主题；没有具体问题时，会简短引导你开始。

**AI 读不到资料？** 按 [使用指南](开始使用.md)提供文件。旧聊天回答过时，可新开聊天使用上面的语句；也可以要求重新读取相关主题正文。

## 一起维护

发现资料过时、记录新进展或形成新方案时，让 AI 先说明拟修改内容。共享更新通过任务分支与拉取请求 [PR] 提交，按授权审核、合并，详见 [贡献指南](CONTRIBUTING.md)。

项目状态以主题中的**信息日期与来源**为准；需求、实现和上线分别记录。当前尚未接入自动同步。
